# Resume Builder

**Resume Builder** — это небольшое frontend-приложение для создания и редактирования резюме прямо в браузере.  
Пользователь может изменить содержимое шаблона, загрузить свою фотографию и сохранить готовый результат в PDF.

Проект сделан как клиентское приложение без backend-части. Основная логика работает на стороне браузера.

## Возможности

- Редактирование содержимого резюме прямо на странице
- Загрузка пользовательской фотографии
- Подстановка фото в шаблон
- Экспорт готового резюме в PDF
- Простая и понятная структура интерфейса
- Кастомная стилизация страницы через CSS

## Стек технологий

- HTML5
- CSS3
- JavaScript
- Vite
- `html2canvas`
- `jsPDF`

## Как запустить проект

Проект запускается через **Vite**.

### 1. Установить зависимости

```bash
npm install
2. Запустить локальный сервер
npm run dev

После этого Vite покажет локальный адрес, по которому будет доступно приложение в браузере.

Почему в проекте нет vite.config.js

Это нормально.
Vite умеет работать без отдельного файла конфигурации, если проект использует стандартные настройки.

То есть для запуска vite.config.js не обязателен.
Если в проекте нет нестандартных alias, proxy, плагинов или специальных путей сборки, отдельный конфиг можно не создавать.

Описание файлов
index.html — основная HTML-страница приложения
main.js — логика загрузки фото и экспорта страницы в PDF
style.css — стили интерфейса и шаблона резюме
Как работает приложение
Редактирование

Основной шаблон резюме отображается прямо на странице.
Пользователь может менять содержимое вручную и подстраивать его под себя.

Загрузка фотографии

Через input для файла пользователь выбирает изображение со своего устройства.
Файл считывается в браузере и сразу подставляется в шаблон.

Экспорт в PDF

После заполнения резюме можно сохранить результат в PDF.
Для этого используется связка:

html2canvas — превращает HTML-блок в изображение
jsPDF — собирает PDF-документ на основе полученного изображения
